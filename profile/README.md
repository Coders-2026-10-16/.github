# ئۇيغۇر ئېيئاي دەرسى UyghurAI | 

## 2026-يىلى 10-ئايلىق سىنىپ

بۇ سىنىپنىڭ رەسمىي GitHub بېتى. دەرس ماتېرىياللىرى، تاپشۇرۇقلار ۋە ئوقۇغۇچىلارنىڭ ئىشلىرى مۇشۇ يەردە ساقلىنىدۇ.

## سىنىپقا كىرگەندىن كېيىن نېمە قىلىمىز؟

1. گىتخاب **GitHub ئىشلەتكۈچى نامىڭىزنى** ئوقۇتقۇچىغا ئەۋەتىڭ. سىنىپقا ئوقۇتقۇچى رۇخسەت قىلغانلارلا قوشۇلىدۇ، ھەر كىم ئۆزلۈكىدىن كىرەلمەيدۇ.
2. ئوقۇتقۇچى سىزنى تەكلىپ قىلغاندىن كېيىن، ئېلخېتىڭىزنى ياكى [github.com/notifications](https://github.com/notifications) نى ئېچىپ، **تەكلىپنى قوبۇل قىلىڭ** (Accept invitation).
3. ئەزا بولغاندىن كېيىن بۇ بەتتىكى **Repositories** نى ئېچىپ، تاپشۇرۇق repository سىنى تېپىڭ.
4. تاپشۇرۇقنىڭ **README** فايلىنى ئەستايىدىل ئوقۇڭ.
5. ئۆز **branch ىڭىزنى** ئېچىپ (branch ئىسمى = ئۆز ئىسمىڭىز)، ئۆز فولدېرىڭىزدا ئىشلەڭ.

## ئاساسىي قائىدە

- ھەر ئوقۇغۇچىنىڭ ئۆز ئىسمىدىكى branch ى ۋە فولدېرى بار. ئارىلىشىپ كەتمەسلىك ئۈچۈن **پەقەت ئۆز ئىسمىڭىزدىكى جايدا** ئىشلەڭ.
- مېيىن **main** branch قا بىۋاسىتە push قىلماڭ.
- باشقىلارنىڭ ھۆججەت قىسقۇچىغا كىرىپ يازغان كودىغا چېقىلماڭ.
